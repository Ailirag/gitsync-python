# Плагины gitsync-py

## Что это

Плагин — обычный Python-модуль с функцией `register(host)`. Он подписывается на события ядра
и получает их синхронно из потока коммитов.

```python
# мой_плагин.py
def register(host):
    host.subscribe("after_commit", on_after_commit)


def on_after_commit(version, work_dir, sha):
    print(f"Версия {version.number} -> {sha}")
```

Запуск:

```bash
gitsync-py sync --workdir ./repo --backend fixture --fixture-root ./снимок --plugin мой_плагин
```

Модуль должен быть импортируемым (в `PYTHONPATH` или установлен пакетом).

## Поддерживаемые события

| Событие | Аргументы | Когда |
|---|---|---|
| `after_history` | `history: list[StorageVersion]`, `current_version: int` | после чтения истории хранилища, до выгрузки |
| `before_commit` | `version: StorageVersion`, `work_dir: Path`, `author: str` | перед коммитом версии, рабочая копия уже обновлена |
| `after_commit` | `version: StorageVersion`, `work_dir: Path`, `sha: str \| None` | после успешного коммита |

Исключение в плагине пишется в лог как предупреждение и не останавливает синхронизацию.
`PluginHost(strict=True)` меняет это поведение на «падать».

## Явные ограничения совместимости

Плагины upstream (OneScript) **не поддерживаются и не будут поддерживаться** этим пакетом:

* `.os`-плагины не загружаются — нет среды OneScript;
* установка плагинов через `opm` (`gitsync plugins install`) не реализована;
* встроенные запакованные плагины (`bindata`) не переносились;
* из более чем 30 событий `МенеджерПодписок` реализованы три, перечисленные выше;
* **подмена стандартной обработки не поддерживается**: в upstream многие события получают
  флаг `СтандартнаяОбработка`, которым плагин отменяет штатное поведение (чтение таблицы
  версий, очистку каталога, выгрузку в исходники, перемещение файлов). Здесь такого
  механизма нет — события только наблюдают.

Если нужна подмена источника версий целиком — реализуйте свой бэкенд по протоколу
`gitsync.backends.StorageBackend` (`fetch_history`, `export_version`) и передайте его
в `SyncManager` из своего кода. Это поддерживаемая точка расширения.
